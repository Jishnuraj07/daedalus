Run `daedalus doctor` and show its output verbatim in a code block.

Do not summarise or interpret it — the point of this command is the raw report,
which is what someone pastes into a bug report. If a backend reports as `null`,
quote the reason it gives and, only if asked, suggest what would enable it.
