Run `daedalus test`. It plays the three tones in order, about a second apart.

Then tell the user, briefly, what each one means:

- rising two notes — a turn finished
- falling two notes — the session needs them
- one low note — something broke

Suggest they set their system volume here, since this is the loudest Daedalus
ever gets.
